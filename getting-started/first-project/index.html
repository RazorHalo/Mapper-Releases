Your First Project¶

This walkthrough takes you from a blank project to parts positioned on a slab, ready for export.

Step 1: Create a New Project¶

Launch Mapper or press Ctrl+N to start a new project.

Step 2: Add a Slab¶

  1. Click Add Slab in the toolbar (or go to Slab > Add Slab)
  2. In the dialog that opens:
    • Click Browse Image... to load a photo of your slab (or drag the image file onto the dialog)
    • Enter the slab dimensions — Width and Height in inches
    • Set the Thickness from the dropdown
    • Give it a Name, Material, and Slab #
    • Adjust the crop rectangle on the image to frame just the stone
  3. Click Add Slab

The slab appears on the canvas with your photo cropped to the stone area.

Tip

If your slab photos are taken at a consistent photo station, see Photo Station Setup to calibrate automatic dimension scaling.

Step 3: Import DXF Parts¶

  1. Click Import DXF in the toolbar (or press Ctrl+I)
  2. Select one or more .dxf files from your file browser
  3. Each file is parsed and added as a part on the canvas

Parts appear as outlined shapes. If Mapper can't find a Job ID in the DXF file, you may be prompted to enter one manually.

Step 4: Position Parts on the Slab¶

  • Click a part to select it (it highlights)
  • Drag the selected part onto the slab
  • The part turns green when it's fully on the slab with no overlaps
  • Use Align to Axis (press A) to snap part edges flush with other parts
  • Use Common Line Cut (press C) to share a cut line between adjacent parts, saving blade kerf

See Moving & Positioning for all the ways to arrange parts.

Step 5: Check the Pattern Match¶

  1. Press Ctrl+R to open the Render Window
  2. Parts are shown with the actual slab texture mapped onto them
  3. Drag parts in the Render Window to fine-tune the assembled countertop appearance
  4. This is where you confirm the stone pattern looks right across all pieces

Step 6: Export¶

When you're satisfied with the layout:

  • DXF Export: Go to File > Export All Slabs to DXF to generate per-slab DXF files for your CNC
  • Labels: Press Ctrl+L to open the Label Generator and print labels for each part
  • PDF Report: Go to File > Generate PDF Report for a shop-floor reference sheet

Step 7: Save Your Project¶

Press Ctrl+S to save your project as a .map file. This bundles everything — slab images, part positions, and all settings — into a single file you can reopen later.
