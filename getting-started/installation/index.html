Installation & Licensing¶

System Requirements¶

  • OS: Windows 10 or later (64-bit)
  • RAM: 4 GB minimum, 8 GB recommended
  • Disk: ~200 MB for the application
  • Display: 1200x600 minimum, 1920x1080 recommended

Installing Mapper¶

  1. Download the latest installer from the releases page
  2. Run the installer and follow the prompts
  3. Launch Mapper from the Start menu or desktop shortcut

Mapper updates automatically — when a new version is available, a notification banner appears at the bottom of the main window. Click Download to fetch the update, then Restart to Update to apply it.

You can also check manually via Help > Check for Updates.

Licensing¶

On first launch, the License Activation window appears.

Free Trial¶

Click Start 30-Day Free Trial to begin using Mapper immediately with full features. The trial period counts calendar days from activation.

Activating a License¶

  1. Enter your license key in the format XXXXX-XXXXX-XXXXX-XXXXX
  2. Click Activate License
  3. The window will confirm successful activation

Note

An internet connection is required for license activation and periodic revalidation. If you're offline during a revalidation check, Mapper will show a warning and try again later.

Deactivating a License¶

To move your license to another computer, click the small Deactivate License link at the bottom of the License Activation window. This frees the license for use on a different machine.

File Associations¶

After installation, Mapper registers the .map file extension. You can:

  • Double-click a .map file in Explorer to open it directly in Mapper
  • Drag and drop a .map file onto the Mapper window to open it
  • Drag and drop .dxf files onto the Mapper window to import them as parts
