Interface Overview¶

The Mapper window is divided into several zones. Here's what each one does.

Menu Bar¶

Access all features through these menus:

  • File — New, Open, Save, Import/Export DXF, PDF Reports, Labels
  • Edit — Undo / Redo
  • View — Zoom, toggle labels/dimensions/warnings, Render Window, theme
  • Slab — Add, Edit, Remove slabs; Layout Settings
  • Part — Add Part, Remove Part, Import DXF
  • Help — Check for Updates, About

See Menus & Toolbar for a complete reference.

Main Toolbar¶

Quick-access buttons for the most common actions:

New | Open | Save | Add Slab | Layout Settings | Add Part | Import DXF | Export DXF | Export All | PDF | Render | Labels

Hover over any button to see its tooltip and keyboard shortcut.

Canvas¶

The large central area is your layout workspace. This is where you see slabs and position parts.

  • Left-click to select parts
  • Drag selected parts to move them
  • Mouse wheel to zoom in/out (centered on cursor)
  • Middle-click drag or Shift + left-drag to pan
  • Rubber-band selection — click and drag on an empty area to select multiple parts

Selection modes

Drag down-right for containment selection (only fully enclosed parts). Drag any other direction for intersection selection (any part the rectangle touches).

Interaction Toolbar¶

A floating toolbar that can be docked to any edge of the canvas (top, right, bottom, or left). Right-click it to change the dock position or icon size (Small / Medium / Large).

It contains:

  • View toggles — Labels, Geometry Warnings, Text Entities, Auto Snap
  • Text modes — Add Text, Edit Text
  • Rotation controls — CCW/CW buttons with angle input
  • Zoom to Fit
  • Interaction modes — Measure Distance, Move by Snap, Align to Axis, Common Line Cut
  • Movement controls — Directional arrows with increment input
  • Undo / Redo

See Interaction Modes for details on each mode.

Right Panel¶

The right side is split into two sections, separated by a draggable divider.

Slab List (top)¶

Shows all slabs in the project. Each entry displays:

  • Thumbnail image
  • Slab name, thickness, material
  • Dimensions and slab number

Click a slab to select it. Use Ctrl + click for multi-selection.

Buttons at the top: Add | Edit | Remove

Properties Panel (bottom)¶

Shows details for the currently selected slab or part.

With a slab selected: Name, Material, Slab #, Lot #, Notes, area and utilization stats.

With a part selected: Job ID, Job Name, Part ID, area.

With multiple items selected: Aggregated summary (counts, combined area, utilization).

Status Bar¶

The bottom bar shows:

  • Current status message
  • Total slabs and total parts (with square footage)
  • Selected part count (with square footage)
  • App version

Update Banner¶

When a new version is available, a banner appears above the status bar with Download and Restart to Update buttons. Dismiss it with the X button.
