Render Window¶

The Render Window shows the assembled countertop with real slab textures mapped onto each part. This is where you verify that the stone pattern flows correctly across all pieces before committing to a cut.

Opening¶

Press Ctrl+R or go to View > Render Window or click Render in the toolbar.

What You See¶

Each part is displayed with the actual slab photo texture clipped and rotated to match where it sits on the slab. The result is a realistic preview of what the assembled countertop will look like after cutting and installation.

Parts also show their outlines, and optional overlays like labels, dimension callouts, text entities, and collision state colors.

Canvas Interaction¶

The Render Window canvas works like the main layout canvas:

Action Result
Click a part Select it
Ctrl + click Multi-select
Drag on empty area Rubber-band selection
Drag a selected part Move it (render position only)
Middle-click drag or Shift + drag Pan the view
Mouse wheel Zoom in/out

Important

Moving parts in the Render Window changes their render position only — it does not affect where they're cut from the slab (the layout position). This lets you adjust the assembled appearance without changing the cutting layout.

Interaction Modes¶

The same modes are available as in the main canvas:

Key Mode
A Align to Axis
M Move by Snap
C Common Line Cut
Esc Select mode

The status bar at the bottom shows the current mode and a reminder of the shortcuts.

Toolbar¶

The Render Window toolbar provides:

  • Toggle Labels — show/hide part labels
  • Toggle Text Entities — show/hide DXF text on parts
  • Text Color — switch between Black, White, or DXF Original text color
  • Toggle Collision Warnings — show/hide collision state colors
  • Rotation — CCW/CW buttons with angle input
  • Zoom to Fit — fit all parts in view
  • Mode toggles — Align to Axis, Move by Snap, Common Line Cut
  • Movement — directional nudge buttons with increment input
  • Z-Order — Bring to Front / Send to Back (controls which part draws on top when overlapping)
  • Undo / Redo — undo render position changes
  • Reset — reset selected part to its DXF original position
  • Reset All — reset all parts to their DXF original positions

Z-Order¶

When parts overlap in the render view, use Bring to Front and Send to Back to control which part appears on top. This is purely visual — it affects the render preview and PDF reports.

Part Groups¶

Groups let you organise parts for the PDF render report. Each group gets its own page in the report, printed in panel order, with any ungrouped parts collected on a final page.

Groups Panel¶

Click Groups in the toolbar (or View > Groups) to open the Groups panel in the right dock.

  • New Group — creates a new group and auto-names it ("Group 1", "Group 2", …). If parts are selected they are assigned to the new group immediately. Rename the group afterwards by double-clicking its name.
  • Rename — double-click a group name to edit it inline.
  • Colour swatch — click the swatch next to a group name to cycle to the next palette colour. That colour is used for canvas overlays (outlines and badges).
  • ⋯ menu — each group row has an overflow menu with:
    • Add selected parts — assign the currently selected parts to this group
    • Remove selected parts — remove the currently selected parts from this group
    • Select parts — select all parts that belong to this group on the canvas
    • Highlight parts — flash the group's parts on the canvas so you can identify them at a glance
    • Move Up / Move Down — reorder groups; this controls the page order in the PDF report
    • Delete group — removes the group; parts are never deleted

Assigning Parts¶

Right-click any part on the canvas to assign or unassign it:

  • Add to group → — shows a submenu of existing groups; pick one to assign the part
  • Remove from group — removes the part from whichever group it currently belongs to (always shown; disabled when the part is not in any group)

A part can belong to at most one group at a time.

Canvas Overlays¶

Click Show Groups in the toolbar to toggle coloured overlays on the canvas. When enabled, each part belonging to a group is drawn with a coloured outline and a small badge in its assigned group colour.

Undo¶

All group changes — creating, renaming, recolouring, reordering, adding/removing parts, and deleting groups — are fully undoable with Ctrl+Z.

Resetting Positions¶

If you've moved parts in the Render Window and want to start over:

  • Reset Selected — go to Part > Reset Selected to DXF Original or click the Reset toolbar button
  • Reset All — go to Part > Reset All to DXF Original or click the Reset All toolbar button

This restores each part's render position to where it was originally defined in the DXF file.
