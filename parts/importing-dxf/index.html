Importing DXF Files¶

DXF files are the primary way to bring countertop shapes into Mapper. Each DXF file becomes a part that you can position on a slab.

How to Import¶

  1. Press Ctrl+I or click Import DXF in the toolbar
  2. Select one or more .dxf files in the file browser
  3. Click Open

Each file is parsed and added as a part in the project. Parts initially appear at their DXF origin position on the canvas.

Drag and Drop

You can also drag .dxf files directly from Explorer onto the Mapper window to import them.

What Gets Imported¶

Mapper reads the following from each DXF file:

  • Part outline — the closed polyline or boundary shape
  • Text entities — any text in the DXF (used for labels, Job ID extraction)
  • Layer information — layer names and colors are preserved
  • Entity colors — original DXF colors are maintained for export

Which Shapes Become Parts¶

A part outline can be drawn as a closed polyline, as a circle, or as separate lines and arcs that join up into a closed shape. The different kinds can be mixed in one drawing.

A closed shape that sits completely inside a larger one becomes a cutout of it (a sink or faucet hole), not a part of its own. This works whichever way each shape was drawn: a circle inside a polyline countertop, or a polyline sink inside a countertop drawn with lines, both become cutouts. Inside means inside the part's true outline, curves included, so a tap hole in the bowed front of a curved top is a cutout.

Leave a gap, and keep cutouts off the edge

Two drawing rules keep parts and cutouts apart:

  • Parts must not touch. Leave a gap between every two parts. Shapes drawn touching each other cannot be told apart from one part with a cutout.
  • A cutout must not touch the edge of its part. Draw a notch (for a farmhouse sink, say) as part of the outline, with the outline stepping in. Do not draw it as a separate closed shape laid on the edge.

A closed shape that touches a part's edge may import as a cutout or as a separate part, depending on how it was drawn.

Borders and frames

A closed border, frame or slab outline drawn around your parts is a shape too. Because the parts sit inside it, they become its cutouts and you get one large part. Remove borders from the drawing before importing. In a drawing with no closed polylines, an unclosed border or wall line does the same: it is treated as closed straight across its open side.

A shape inside a cutout (a drain circle drawn inside a sink, say) belongs to the same part and shows as an island of stone inside the cutout. It is exported with the part.

If a cutout is drawn twice in the same place — for example a sink on the cutout layer and again on a CNC layer — Mapper draws it once, so it shows as one cutout. Both copies are still exported, each on its own layer. The same applies to two cutouts of exactly the same overall size in the same place, such as a round sink drawn inside a square one.

A few things are deliberately not read as stone:

  • Balloons on the label layers (a shape drawn around a part's label) are annotation. In a drawing with closed polylines, a balloon drawn as a circle, as a two-point polyline circle, or with lines and arcs is not turned into a cutout. A balloon drawn as a closed polyline with three or more points is still read as a shape. The label layers are set in the text settings.
  • Loose lines or arcs that do not close into a shape, in a drawing that also has closed polylines, are treated as annotation (dimension lines, seam marks) and are not imported. The status bar tells you how many were left out, for example "Imported 3 part(s) from 1 file(s) — 2 open line/arc shapes were not imported". If one of them was meant to be a part or a cutout, close the shape in your CAD program and import again.
  • Open polylines are not imported, and are not counted in that note.
  • Filled dots and rings (AutoCAD's DONUT: a two-point polyline circle drawn with a line width) are markers, not holes, and are not imported. To cut a round hole, draw a circle, or a polyline circle with no width.

In a drawing with no closed polylines at all, an unclosed outline made of lines and arcs is still imported and its gap is marked on the canvas so you can find and fix it. Closed shapes inside it are still its cutouts: the outline is treated as closed straight across the gap.

Job ID Extraction¶

Mapper automatically tries to find a Job ID in each imported DXF. The Job ID links the part to a specific job or order.

By default, Mapper searches for a pattern like RS-12345 in:

  • Text entities within the DXF
  • The file path
  • The filename

If no Job ID is found and Prompt when not found is enabled, a dialog appears asking you to enter one manually. You can type a Job ID or click Skip.

Job Name Extraction¶

The Job Name is extracted from the DXF filename using a separate regex pattern. This typically captures the descriptive part of the filename (e.g., "Smith Kitchen" from RS-12345 Smith Kitchen.dxf).

Configuring Import Settings¶

Go to File > DXF Import Settings... to customize:

Job ID Extraction¶

  • Regex pattern — the pattern to search for (default: RS\s?-?\s?\d{4,5})
  • Case insensitive — ignore case when matching
  • Search in — which sources to search (Text Entities, File Path, Filename)
  • Prompt when not found — show an input dialog when no match is found

Job Name Extraction¶

  • Regex pattern — applied to the filename only (extension stripped)
  • Case insensitive — ignore case when matching

Batch Import¶

Select multiple DXF files at once in the file picker to import an entire job in one action. Each file becomes a separate part, and Job IDs are extracted individually from each file.
