Importing DXF Files¶

DXF files are the primary way to bring countertop shapes into Mapper. Each DXF file becomes a part that you can position on a slab.

How to Import¶

  1. Press Ctrl+I or click Import DXF in the toolbar
  2. Select one or more .dxf files in the file browser
  3. Click Open

Each file is parsed and added as a part in the project. Parts initially appear at their DXF origin position on the canvas.

Drag and Drop

You can also drag .dxf files directly from Explorer onto the Mapper window to import them.

What Gets Imported¶

Mapper reads the following from each DXF file:

  • Part outline — the closed polyline or boundary shape
  • Text entities — any text in the DXF (used for labels, Job ID extraction)
  • Layer information — layer names and colors are preserved
  • Entity colors — original DXF colors are maintained for export

Job ID Extraction¶

Mapper automatically tries to find a Job ID in each imported DXF. The Job ID links the part to a specific job or order.

By default, Mapper searches for a pattern like RS-12345 in:

  • Text entities within the DXF
  • The file path
  • The filename

If no Job ID is found and Prompt when not found is enabled, a dialog appears asking you to enter one manually. You can type a Job ID or click Skip.

Job Name Extraction¶

The Job Name is extracted from the DXF filename using a separate regex pattern. This typically captures the descriptive part of the filename (e.g., "Smith Kitchen" from RS-12345 Smith Kitchen.dxf).

Configuring Import Settings¶

Go to File > DXF Import Settings... to customize:

Job ID Extraction¶

  • Regex pattern — the pattern to search for (default: RS\s?-?\s?\d{4,5})
  • Case insensitive — ignore case when matching
  • Search in — which sources to search (Text Entities, File Path, Filename)
  • Prompt when not found — show an input dialog when no match is found

Job Name Extraction¶

  • Regex pattern — applied to the filename only (extension stripped)
  • Case insensitive — ignore case when matching

Batch Import¶

Select multiple DXF files at once in the file picker to import an entire job in one action. Each file becomes a separate part, and Job IDs are extracted individually from each file.
