Mapper User Guide¶

Welcome to Mapper — stone fabrication layout software for positioning countertop parts on slabs, pattern matching with slab photos, and exporting DXF files for CNC cutting.

What Mapper Does¶

Mapper helps you take countertop shapes from DXF files, place them on photos of your actual stone slabs, and arrange everything for the best pattern match. When you're done, export per-slab DXF files to send directly to your CNC saw, print labels for each part, and generate PDF reports for your shop floor.

Typical Workflow¶

Import DXF → Load Slab Photos → Position Parts on Slabs → Pattern Match in Render View → Export DXF → Print Labels
  1. Import your DXF files — each DXF becomes a part (countertop piece) in the project
  2. Add your slabs — load a photo, set dimensions, crop to the stone
  3. Drag parts onto slabs — position them where you want to cut
  4. Open the Render Window — see the assembled countertop with real slab textures mapped onto each part
  5. Export — generate per-slab DXF files for the CNC, PDF reports for the shop, and labels for each piece
