Menus & Toolbar Reference¶

File Menu¶

Item Shortcut Description
New Ctrl+N Create a new empty project
Open... Ctrl+O Open a .map project file
Save Ctrl+S Save the current project
Save As... Ctrl+Shift+S Save to a new file location
DXF Import Settings... — Configure how DXF files are parsed on import
DXF Export Settings... — Configure what's included in exported DXF files
Export Selected Slab(s) to DXF... — Export DXF for selected slabs only
Export All Slabs to DXF... — Export DXF for every slab
Generate PDF Report... — Open PDF report settings and generate
Label Generator... Ctrl+L Open the Label Generator window
Exit Alt+F4 Close Mapper

Edit Menu¶

Item Shortcut Description
Undo Ctrl+Z Reverse the last action
Redo Ctrl+Y Re-apply the last undone action

View Menu¶

Item Shortcut Description
Zoom In Ctrl++ Increase canvas zoom
Zoom Out Ctrl+- Decrease canvas zoom
Zoom to Fit Ctrl+0 Fit all content in the viewport
Show Labels — Toggle part label overlays on/off
Show Dimensions — Toggle dimension annotations on/off
Show Geometry Warnings — Toggle collision warning overlays on/off
Render Window Ctrl+R Open the Render Window
Toggle Theme — Switch between dark and light mode

Slab Menu¶

Item Description
Add Slab Open the Add Slab dialog
Edit Slab... Edit the selected slab's properties and image
Remove Slab Delete selected slab(s) from the project
Layout Settings... Configure the slab grid layout
Relayout All Slabs Reposition all slabs using current layout settings

Part Menu¶

Item Shortcut Description
Add Part Ctrl+P Manually create a new part
Remove Part Del Delete selected part(s)
Import DXF... Ctrl+I Import DXF files as parts

Help Menu¶

Item Description
Check for Updates... Check for a newer version of Mapper
About Mapper Show version and application information
